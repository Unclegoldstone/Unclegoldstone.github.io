# 页面转场

首页（小站入口）与 Blogs 共用 `src/components/PageTransition.vue`，在两页根组件各挂载一次。

配置位于 `src/transitions/config.js`：

- `style: 'map'` 为地图动画，`'fade'` 为短淡入，`'none'` 关闭拦截并使用浏览器直接跳转。
- `durationMs: 1500` 为离开页面前的总动画时长：卷轴展开 160ms、移动 1200ms、抵达停留 140ms。网络加载时间不计入动画时长。
- `path` 同时控制 SVG 虚线与人物移动。首页到 Blogs 正向，返回首页反向。新增路线时应继续共享路径数据。
- `walkFps` 调整迈步频率。

仅拦截本站首页与 Blogs 间的普通同标签页链接。保留 URL 的文章与首页锚点；页内跳转、文章间切换、外链、下载、新标签页及修饰键点击不触发地图。系统偏好减少动态效果或素材尚未就绪时使用 120ms 简短淡入。返回浏览器历史时清理遮罩，避免恢复到被锁定的页面。

正式素材位于 `src/assets/transitions/`，已从设计预览复制，构建和发布不依赖被忽略的 `design-previews/`。

地图与人物动作帧使用内置图像生成工具制作；地图沿用已审核的布局，原来的装饰虚线已清除，正式虚线由路径数据绘制。

地图正式使用 `world-map-transparent.png`：卷轴外部为透明通道，统一使用转场组件的底色，避免原图深青色矩形背景与遮罩出现色差。底图透明化使用内置图像工具，仅移除卷轴外侧背景，保留画布尺寸与地图布局。


## 三地点地图

Works 铁匠铺使用独立透明素材 works-smithy.png，通过 SVG 放置在底图左侧空白区域，不将地点烘焙进背景图。位置、三条路线与手机视图范围集中在 src/transitions/routes.js。首页/Blog、首页/Works、Blog/Works 均支持双向转场。当前路径高亮，其余连接显示为较浅虚线，人物始终沿当前高亮路径移动。config.js 保留时长、迈步频率和动画样式设置。
