# 内容维护

网站内容直接保存在本地文件中，无需数据库。修改后重新构建即可更新静态网站。

## 随笔

编辑 `src/data/notes.js`，每个对象对应一篇随笔，按数组顺序展示：

```js
{
  title: '文章标题',
  date: '10.11',
  year: '2026',
  category: '生活碎片',
  body: '第一段正文。\n\n第二段正文。'
}
```

标题应保持唯一。正文是纯文本，使用 `\n\n` 分段。

## 作品

编辑 `src/data/projects.js`，每个对象对应一个作品：

```js
{
  title: '作品名称',
  type: '个人项目',
  scene: 'desk',
  no: '03',
  desc: '作品的简短介绍。',
  tags: ['Vue 3', '像素风'],
  body: '作品的详细介绍。'
}
```

`no` 是唯一编号；`scene` 使用现有场景 `desk` 或 `garden`。作品的 `type` 填写“个人项目”、“合作项目”或“小工具”，页面提供“全部、个人项目、合作项目、小工具”四个筛选选项。作品数量及 A 栏的随笔/作品数量自动跟随数据更新。卡片沿水平方向排列，超出可见区域时可以通过滚动条、触控板或手机滑动浏览。

## 页面结构与样式

- `src/App.vue`：整体三栏布局、导航、主题切换和共用详情弹窗。
- `src/components/NotesSection.vue`：随笔区块的标题与列表结构。
- `src/components/ProjectsSection.vue`：作品区块的标题、筛选与卡片结构。
- `src/style.css`：公共样式及响应式布局。

修改内容时通常只需要编辑 `src/data/`，无需修改页面组件。未来长文章增多时，可以再接入 Markdown；当前没有引入 Markdown 或额外依赖。

## 首页打字文本

编辑 `docs/HOME.md`，每行一句，标题、HTML 注释和空行不会参与抽取。随机选择一句逐字打印，完整显示后停留约 4 秒，再逐字删除并随机打印另一句，持续循环；有多条不同文本时不会连续重复同一句。支持中英文。启用减少动态效果的设备直接显示完整文本。

显示组件位于 `src/components/HomeTyping.vue`。文本在构建时读取，修改后需要重新构建并发布。
## 首页时段插画

`src/components/DayScene.vue` 根据访问者设备的本地时间选图，每分钟检查一次，重新打开或返回页面时也会刷新。图画下方会显示当前时段名称。

时间映射保存在 `src/data/dayScenes.js`：00–03 午夜、03–06 日出、06–09 早晨、09–12 中午、12–15 下午、15–18 傍晚、18–21 黄昏、21–24 夜晚。均包含起始时间、不包含结束时间。这是固定的视觉时间分段，不计算所在地的真实日出日落。

八张 SVG 原图保存在 `src/assets/day-scenes/`，构建时自动打包。独立设计预览页保留在 `design-previews/day-scenes-v1/`。
## 作品封面与详情图片

作品数据可配置 `cover`（卡片封面）和 `detailImages`（详情图片地址数组），两者独立。使用项目内资源时，先在 `src/data/projects.js` 顶部导入图片，再将导入的变量填写到对应字段。

详情优先使用 `detailImages`，没有单独详情图时使用 `cover`，两者都没有时沿用 `scene` 插画。详情图片置于像素风边框中，保持比例完整显示；多张图片使用手动轮播，可通过左右按钮、序号按钮、键盘方向键或手机横向滑动切换。单图隐藏切换按钮；点击图片可在新标签页查看原图。实际作品可设置 `isExample: false`，隐藏示例内容标记。

SrunKeeper 原始详情图位于 `src/assets/projects/srunkeeper-detail.png`；已确认的像素封面位于 `src/assets/projects/srunkeeper-cover.png`，卡片使用像素封面，详情使用原始截图。
## 作品发布日期

每个作品都预留 `publishedAt` 字段，由你自行设置实际发布日期。例如：

```js
publishedAt: '2026-10-15',
```

日期格式为 `YYYY-MM-DD`。填写后，详情弹窗左上角原来 `GOLDSTONE / PROJECT` 的位置显示“发布于 2026-10-15”。留空时显示“发布日期待补充”。日期不会根据当前时间自动生成或变更；卡片布局和作品顺序保持不变，随笔弹窗不受影响。
