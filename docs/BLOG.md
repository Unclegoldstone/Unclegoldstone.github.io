# 写一篇 Blog

## 1. 新建 Markdown 文件

推荐先复制 `src/blogs/posts/article.tmplate`，将副本改名为 `my-article.md`，再修改头部信息和正文。模板中的说明保存在 YAML 注释中，不会出现在文章里。原始 `.tmplate` 文件不会被加载为文章，可一直保留。

在 `src/blogs/posts/` 中新增 `my-first-blog.md`。文件名用英文、数字和短横线；发布后保持不变，因为它决定文章地址。

````markdown
---
title: 我的第一篇博客
date: '2026-11-12'
category: [生活碎片, 个人成长]
excerpt: 这是一段简短摘要。
---

这里是正文，可以使用 **加粗**、*斜体* 和 [项目链接](https://github.com/Unclegoldstone)。

## 今天的发现

- 一段文字
- 一张照片

![图片说明](./assests/my-photo.jpg)

> 给未来的自己留一点痕迹。

## 一段代码

```js
console.log('Hello, world!')
```
````

## 2. 添加图片

把示例中的图片放到 `public./assests/my-photo.jpg`，文章中使用 `./assests/my-photo.jpg` 引用，文件名和路径要与 Markdown 一致。也支持 PNG、WebP、GIF、SVG 和 AVIF，或完整 HTTPS 图片地址。

图片按原比例适配正文宽度，点击可查看原图。文件随项目构建，不依赖外部图床。Blog 插图统一存放在 `src/blogs/posts/assests/`（目录名为 assests），使用相对于文章的路径引用。请确保文件存在且大小写一致，图片路径有误时，该文章会被跳过，本地页面会显示具体错误，其他文章正常加载。

## 3. 预览和发布

运行 `npm.cmd run dev`，浏览器访问终端地址加 `/blog.html`。文章自动加入列表并按日期倒序排列，无需修改 JS 文件。

该文章地址是 `/blog.html#my-first-blog`。如果需要文件重命名而保留链接，可在头部显式填写 `slug: my-first-blog`。slug 不能重复。

`date` 必须是有效的 `YYYY-MM-DD` 日期。省略 `category` 默认归入“随笔”；省略 `excerpt` 自动提取正文首段。头部添加 `draft: true` 可将文章排除在列表和阅读页之外。

二级和三级标题会自动出现在文章目录中，一级正文标题也支持，但通常直接从 `##` 开始，因为页面已有文章标题。支持列表、引用、表格、分隔线及代码块；代码块以等宽字体展示，暂未添加语法高亮。

Markdown 中的原始 HTML 不执行。当前只支持标准 Markdown，不支持 MDX、Vue 组件或数学公式插件。

更新线上版本时，自行提交推送源文件即可，GitHub Actions 将重新构建。首页“最近的碎碎念”已接入 Blog，自动读取最新三篇已发布文章的摘要。文章与“查看全部文章”入口均在当前标签页打开。

## 一篇文章属于多个分类

头部可填写 `category: [开发记录, Vue, 个人项目]`，也可以分行填写：

```yaml
category:
  - 开发记录
  - Vue
  - 个人项目
```

旧写法 `category: 开发记录` 仍然有效。文章会在任一所属分类下出现，每个分类显示自己的文章数量；“全部”中的文章不重复。同一分类重复填写会自动去重，列表和阅读页均展示全部分类。不要将“全部”作为分类名称，它是保留的筛选选项。
## 文件名和加载错误

支持 `A.md`、`my-post.md` 和中文文件名。文件名或显式 `slug` 可包含文字、数字、短横线和下划线，不能包含空格、斜线、问号等路径符号；发布后应保持不变。

单篇文章的 YAML、日期、图片路径或 slug 有误时，该文章会被跳过，主页和 Blog 仍可正常打开。本地开发页面会显示出错文件与原因，修正并保存后会重新加载。重复 slug 也会提示，请为不同文章使用不同标识。
