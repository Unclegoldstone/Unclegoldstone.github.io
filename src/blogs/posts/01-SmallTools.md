# 电脑维护

这里网罗一些我日常维护电脑用的小工具

## 硬盘检测与数据备份

### DiskGenius | 磁盘管理与硬盘检测工具

DiskGenius 是一款 Windows 磁盘维护工具。 最常见的用法是查看硬盘健康信息、验收新机械硬盘，以及更换硬盘时克隆旧盘。它也支持创建、调整和格式化分区，以及尝试恢复误删的文件或丢失的分区。

下载link: [DiskGenius – 正式版下载|免费下载](https://www.diskgenius.cn/download.php)

教程文档: [软件帮助 - DiskGenius](https://www.diskgenius.cn/help/) 

### SpaceSniffer | 磁盘空间管理工具

<img src="assets\image-20261118110102413.png" alt="image-20261118110102413" style="zoom: 67%;" />

**SpaceSniffer 是一款免费的 Windows 磁盘空间分析工具，解压即可运行。** 它会扫描选定的磁盘或文件夹，用矩形树图（Treemap）显示空间占用。方块越大，代表文件或文件夹占用的空间越多。点击大方块可以逐层查看里面的内容。

官网 : [SpaceSniffer, find lost disk space the easy way.](https://www.uderzo.it/main_products/space_sniffer/)



# 杂七杂八

## Token Monitor | AI编程工具用量监控

<img src="assets\image-20261118112038306.png" alt="image-20261118112038306" style="zoom: 25%;" />

一款开源桌面工具，可以把 **Codex、Claude Code、Cursor** 等 AI 编程工具的用量、额度和会话记录集中显示。Windows 10/11 有安装版和便携版，也支持 macOS 和 Linux。

它支持很方便的查询如下内容

- 日、月、总Token用量统计，趋势等
- 根据所用的模型， 自动计算大致消费情况
- 默认只读本地日志， 配置的当也可以把服务器内的用量汇总到同一面板

官网&下载link: [Token Monitor Github link](https://github.com/Javis603/token-monitor)
