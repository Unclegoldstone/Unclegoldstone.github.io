# 一点关于在AI时代，做计算机这一行知识广度和深度的思考

整一个2026年， 年初和年末给我的感觉就像是跨越了一个大时代一样，回想自己在25年用AI, 还只是停留在辅助编程上， 做项目，跑实验之类的东西都还是得自己去打磨，自己调参数的; 而现在的模型, 我给出实验方案，给出我想要的目标以后， 基本就能自己烧token替我猛猛干了，效率高了不知道多少倍。 并且整个行业， 甚至整个社会感觉发展都被按了加速键， 以及大厂都在裁员，降本增效， 这也让我对自己的未来是愈发担心。

我担心的事情就是 : 我现在读研以后会不会`毕业即失业`。

我最初学计算机，也就是在AI兴起之前的几年， 给自己定下的方向是: `广度优先`，也就是说知识面一定要广，这样适应性就会好，不至于在一棵树上吊死。这导致了目前我在计算机的领域里什么都沾了一些, 技能树比较广，但普遍不深，常见的小东西都玩过, 比如说: 

- 计算机视觉里做过人像分割、常见的分类, 机器学习、深度学习的法子也都玩过；
- 自然语言处理，使用特定的文本数据微调过基础的模型
- 机器人 : 用过ROS， 也玩过机器狗啥的
- 传统前端 : 学完网页三件套和一些常见的框架以后AI就给它干完了也啥好说了
- 杂七杂八的小工具 : 比如当时在22年纯手搓了一些游戏的自动化脚本，然后搞拨号脚本啥的.

为何没有深入下去， 因为我没想好以后具体会留在计算机这一行具体的哪一个领域内， 以及一个领域的知识， 有了一定深度以后再往下挖掘， 所需要的时间和难度都会上升。

以前我的观点是: 学的广可以哪里着火了需要搭把手你就可以去哪里， 起码不至于找不到班上。

但是现在来看， AI发展到这个程度， 最不差的就是`广度`, 大模型的知识面的广度是常人所不能及的。以及现在使用AI的门槛越来越低， 先前还需要特别明晰的指令才能得到想要的输出， 任何人都可以给AI一个模糊的概念， 即可快速得到一个demo, 这就导致了如果对于一个领域的知识， 仅仅是浮于表面， 不往深了走， 必然导致一个极容易被优化掉的结果。 

也就是说，现在`深度`的意义是要远大于`广度`的, 现在仅仅停留在传统的软件开发上， 可替代性太大了， 必须得进化出一些自己的不可替代性。

乐观点想， 也许以前做的并不算全是无用功， 已有的CV、NLP、机器人等的知识， 并不需要全部推翻，起码入门起来不会花特别多的时间了。但是，得在今年乃至毕业前的这段时间里， 选定一个主线，也就是确定好自己的就业方向， 把某一个方向往深了做。
